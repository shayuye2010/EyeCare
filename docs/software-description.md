## 一、软件概述

EyeCare 亮睛睛是一款面向 Windows 用户的护眼提醒桌面软件。软件通过可配置的专注计时和休息提醒，帮助用户形成规律的远眺、眨眼和短暂休息习惯。软件支持托盘运行、悬浮倒计时、休息遮挡、统计记录和多种提醒方式，适合长时间使用电脑办公、学习或创作的用户。

软件采用网页技术实现交互界面，并通过 Tauri 封装为 Windows 桌面应用。计时、状态、设置和统计数据在本机处理和保存，不依赖在线账户或远程服务。

## 三、主要功能

### 3.1 护眼计时模式

软件提供 20-20-20 护眼模式、番茄专注模式和自定义模式。20-20-20 模式默认每专注 20 分钟提醒用户远眺约 6 米外的目标至少 20 秒；番茄模式默认专注 25 分钟；自定义模式允许用户将专注时间设置为 1 至 180 分钟。

### 3.2 倒计时控制

主界面显示当前模式、剩余时间和计时状态。用户可以暂停、继续、重置计时，也可以通过“立即开始休息”直接进入休息流程。软件按照当前模式计算计时周期，并在周期结束后自动建立下一周期，避免计时停止。

### 3.3 分级提醒

软件支持智能分级提醒、桌面提醒卡片、屏幕边缘闪烁和角落卡片等提醒方式。智能提醒会先显示轻量提醒，用户未处理时逐步增强提示。提醒设计为不自动替用户完成休息确认，用户可以选择现在休息、延后或跳过。

### 3.4 休息遮挡与练习

进入休息后，软件显示休息遮挡界面和剩余休息时间，并提供远眺放松、转动眼球和深度呼吸等练习选项。休息流程至少持续 1 分钟后，完成和关闭操作才会启用，以帮助用户真正离开持续近距离用眼状态。

### 3.5 托盘与悬浮倒计时

软件支持最小化到系统托盘、从托盘恢复主窗口、托盘暂停计时、托盘发起休息和退出应用。用户还可以开启悬浮倒计时窗口，在不恢复主界面的情况下查看剩余时间。

### 3.6 系统体验

软件支持单实例运行、Windows 原生窗口操作、多显示器桌面提醒、全屏应用检测与提醒顺延、开机启动、提示音量、减少动效和键盘 Escape 操作。

### 3.7 设置与统计

设置页面用于管理计时提醒、提示音、智能避让、开机启动和悬浮倒计时等选项。软件在本机记录当日完成休息次数、跳过提醒次数和专注分钟数，并在统计页面展示当日汇总。

## 四、软件操作流程

1. 启动软件，主窗口显示当前护眼模式和专注倒计时。
2. 在模式标签中选择 20-20-20、番茄专注或自定义模式。
3. 根据需要在提醒设置或偏好设置中调整计时、提醒和系统体验选项。
4. 软件在专注周期结束时发出提醒，用户点击开始休息。
5. 休息界面显示剩余时间，用户可选择练习方式。
6. 休息达到最低时长后，用户点击完成休息，软件记录本次完成并进入下一轮计时。
7. 用户也可以通过延后、跳过、暂停、重置或托盘菜单管理当前流程。

## 六、软件数据与安全说明

软件设置和当日统计使用浏览器本地存储保存在用户本机。软件不要求注册账户，不主动上传计时数据。软件对读取到的历史设置进行版本迁移和字段校验，对计时、布尔值和统计数字进行边界处理，以保证异常数据不会导致程序无法启动。

## 七、技术实现概要

前端模块负责界面渲染、用户交互、计时状态、提醒编排、本地数据读写和统计展示；Rust/Tauri 模块负责系统托盘、原生窗口、悬浮倒计时、多显示器定位、全屏应用检测、单实例和开机启动等桌面能力。前端通过 Tauri 命令和事件与桌面端模块通信。
